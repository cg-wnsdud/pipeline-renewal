## 2. 표: VLM 이 문구와 구조를 함께 읽는 공통 경로(table-cells/1)

### 2-1. 입력·호출

- 대상: OCR table 후보(layout label=table) 전부. 한 요청에 표 하나.
- 이미지: 원본 표 영역 crop(표시 없음) + 문맥 이미지(그 영역이 속한 페이지/타일, page-band 정책으로 나뉘는 페이지는 그 띠. 대상 바깥을 어둡게 하고 바깥 3px 테두리, docs/10 조건 B 와 같은 방식).
- OCR 후보는 crop/3 표현(문자열 순, 출처 표시). 셀 구분·행 순서의 정답이 아니라고 명시.
- crop·page-first 두 읽기 모드에서 같은 경로(`--table-read cells`). page-first 의 1차 page 응답 rows 는 trace 로만 남는다.
- 기존 경로(`--table-read legacy`, 기본): 재현용으로 유지하되, 일반 재판독이 표 후보 text 를 바꾸고 rows 를 1차 값으로 남기면 품질 검토 `table_text_rows_from_different_reads` 를 단다(문구 변경 없음).

### 2-2. 최소 구조 계약

응답 하나 = `{region_id, is_table, text, n_rows, n_cols, cells[{row, col, rowspan, colspan, text}], uncertain, notes}`.

- row/col 은 0부터의 논리 위치(픽셀 아님). 병합 셀 문구는 시작 셀에 한 번만, 적용 범위는 span.
- 격자의 모든 위치는 정확히 한 셀(시작 셀 또는 그 span)이 덮는다. 실제 빈 셀은 text "" 인 셀로 명시. 따라서 병합으로 덮인 위치와 실제 빈 셀이 구분된다.
- 계약 검사(기계적): 정수·0 이상, span ≥ 1, 격자 범위 안, 위치 중복 덮임 없음, 덮이지 않은 위치 없음, is_table=false 이면 cells 비움.
- text 와 cells 는 같은 응답을 하나의 후보로 선택·저장한다. rows 는 cells 에서 변환한 호환 보기(시작 셀 문구, 덮인 위치 "")이며 별도 정답으로 만들지 않는다.
- 표 밖 캡션·주석이 같은 bbox 안에 있으면 text 에만 둔다. 영역 bbox 는 기존 표 bbox 하나.
- 계약 실패·시간 초과: page-first 는 1차 page 응답의 text+rows 묶음(같은 응답)을 유지하고 `table_structure_failed`, crop 은 text null·구조 unknown. 부분 응답을 조합하지 않는다.
- 런타임 검토: rows 는 cells 에서 변환되므로 기존 `table_rows_incomplete`(셀 문구가 text 글자를 덮는 비율 < 0.85) 를 그대로 쓴다(캡션·각주가 text 에만 있는 합법적 차이를 고려해 문턱 유지). 1차 page 응답 rows 는 trace(page_rows)에 보존.

## 3. 순서 확인 조건(simple-column-order/1)
