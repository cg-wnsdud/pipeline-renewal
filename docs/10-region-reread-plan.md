# 10. 영역 재판독(region-reread/1): 영역 소속·읽기 구조 확인(실행 전 고정, 2026-10-26)

지시서: `page-first-v2-review-2026-10-26/crop-resolution-and-next-prompt.md`.

**범위**: 영역 소속(외부 문구 유입)과 읽기 구조(좌우 블록, 항목명→값, 실제 반복 위치)를 확인하는 방식만 다룬다.

**바꾸지 않는 것**:

- crop 해상도(원본 픽셀 보존 확인됨)
- 정상 페이지 OCR
- 띠 정책
- 승인된 긴 이미지 경계와 정책

## 1. 바꾸는 것

### 확인 지시(region-patch/1 → region-reread/1)

- '1차 구조는 다시 쓰지 않는다'는 전제를 없앤다. 1차는 틀릴 수 있는 초안이다.
- 확인 VLM이 원본에서 대상 영역 하나의 **완결된 text 후보**를 직접 쓴다. 삽입·치환·삭제 지시 방식은 쓰지 않고, OCR 문자열 삽입이나 후보 합치기도 하지 않는다.
- 지시 내용:
  - 출력은 대상 상자 안 문구만 쓴다. 문맥 이미지에서만 보이는 이웃 문구는 넣지 않는다.
  - 좌우 블록은 한 블록을 끝까지 쓴 뒤 다음 블록을 쓰고, 블록 제목은 그 블록 앞에 둔다.
  - 여러 줄 항목명은 끝까지 이은 뒤 값 전체를 쓴다.
  - 도해는 연결된 요소끼리 묶는다.
  - 1차와 원본이 다르면 원본대로 고치고, 맞는 내용은 보존한다.
  - OCR은 빠진 글자 확인용이다. 나열하지 않고, OCR에 없다고 원본 글자를 버리지 않는다.
  - 원본에 실제로 반복된 문구는 각 위치에 맞게 쓰고, 같은 위치를 두 번 쓰지 않는다.
  - 불명확하면 uncertain과 notes를 남긴다.
- 출력 필드: `region_id`, `text`, `uncertain`, `changes`(1차 대비 바뀐 점 분류, trace 전용), `notes`. 최종 text에 '항목명:' 같은 문구를 만들지 않는다.

### 비교 조건

어느 조건이든 한 요청은 한 영역만 다룬다.

| 조건 | 입력 |
|---|---|
| A | 원본 영역 crop(표시 없음) 1장 + 1차 text + OCR 후보 |
| B | A + 문맥 이미지 1장. 1차 판독에 쓴 원본 페이지·띠·타일에서, 대상 상자 바깥을 반투명하게 어둡게 하고 상자 바깥 3px에 테두리를 그린다. 대상 상자 안 픽셀은 바꾸지 않는다. 요청 문구에 두 이미지의 역할, crop의 원본 좌표, 문맥 이미지 안 대상 bbox를 적는다 |

### 후보 선택 정책

결과를 보기 전에 고정한다. 운영 로직은 정답 자료를 보지 않는다.

1. **재판독 계약 실패**(HTTP·JSON·ID·잘림): 1차를 유지하고 품질 검토 `reread_failed`를 단다.
2. **재판독 성공**: 재판독 text를 쓴다. 단, 아래 손상 신호가 있으면 1차를 유지하고 `reread_conflict`를 단다.
   - 영역 OCR 근거(배정 + 영역 안 비율 0.5 이상 경계) 줄이 재판독에 덮이는 비율이 1차보다 0.05 넘게 낮다.
   - 동시에 그 비율이 0.85 미만이다.
3. 선택 뒤에도 기존 검토 신호(상자 밖 OCR 문구, 반복 문구, 숫자 불일치, OCR 불일치)를 최종 text에 다시 계산해 표시한다. 해소되지 않은 문제를 성공 처리하지 않는다.
4. 1차·재판독 후보, 선택 출처, 재판독 changes·notes를 trace에 모두 남긴다.

**채택 조건**: 선택 정책을 적용한 최종 후보가 다음을 만족해야 한다.

- 핵심 4영역 중 3영역 이상에서 2회 모두 판정을 통과한다.

**채택 뒤 통합**: 채택되면 기존 확인 조건(상자 밖 문구, 반복, 누락, 작은 글자 등)에 해당하는 영역에만 재판독을 연결한다. 표 후보는 text만 재판독하고, rows는 페이지 판독 값을 유지한다. 그다음 19페이지 최종 결과를 새 폴더에 만든다.

**미채택**: 어느 조건도 채택 조건을 만족하지 못하면 관측된 주원인 하나를 겨냥한 조건 1개만 사전 계획해 추가한다. 그래도 실패하면 전체 재실행 없이 비교 자료와 실패 근거를 보고한다.

### 해석과 남은 오류

- **확인 방식**: 보완(patch) 방식은 외부 문구·구조 오류를 거의 고치지 못했다(고칠 점 0건 반환). 재판독(B)은 원본에서 완결된 후보를 써서 L016·L022 구조와 L004 대부분을 바로잡았다.
- **실행 간 변동**: 같은 지시·입력에서도 결과가 갈렸다.
  - L004: 작은 비교 2회는 완전 통과, 최종 실행은 1줄 유입.
  - L010: 실험 1회와 최종에서 같은 중복.
  - 이런 잔여 오류는 검토 신호(`text_from_outside_box`, `repeated_text`)로 표시된다.
- **응답 시간 초과**: 최종 3건(h01 문서 영역), 실험 1건. 모두 1차 판독을 유지하고 `reread_failed`로 표시했다.
- **기본값**: CLI의 `--read-mode` 기본값은 crop 그대로다. 기본값 변경은 회귀(새 오류 11곳)와 원문 기준 검토 뒤 결정한다. 이번에는 승인을 요청하지 않는다. `--read-mode page-first`의 확인 방식 기본값은 `--verify-mode reread`다.
